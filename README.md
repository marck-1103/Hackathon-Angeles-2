# Mente Sana

## Descripción general

Mente Sana es un prototipo de plataforma web educativa orientada al autocuidado, el bienestar emocional y la salud mental.

La plataforma combina información sobre salud mental con actividades de bienestar,seguimiento del progreso, un espacio personal, comunidad y acompañamiento mediante Mimo, el compañero virtual de la plataforma.

El proyecto busca convertir el cuidado de la salud mental en pequeños pasos cotidianos mediante una experiencia sencilla, interactiva y accesible.

## Funcionalidades principales

- Consulta de información sobre salud mental y bienestar emocional.
- Actividades de autocuidado y bienestar.
- Registro del estado emocional.
- Sistema de Mentas como moneda.
- Seguimiento de progreso y rachas.
- Espacio personal del usuario.
- Muro de la comunidad.
- Chatbot de Mimo para acompañamiento general.
- Recursos de ayuda y contacto de emergencia.
- Interfaz responsive para diferentes dispositivos.
- Traducción del contenido a varios idiomas.
- Soporte para navegación mediante teclado y lectores de pantalla.

## Tecnologías utilizadas

- HTML5: estructura y contenido semántico del sitio.
- CSS3: diseño visual, responsive y estilos de la interfaz.
- JavaScript: interactividad, navegación, actividades, gamificación, chatbot y funcionalidades de accesibilidad.
- LocalStorage: almacenamiento local de información del prototipo.
- Google Translate: traducción del contenido a diferentes idiomas.
- SVG / WEBP: recursos gráficos, logotipo e iconografía.

## Instalación básica

Mente Sana es un proyecto frontend y no requiere instalación de dependencias ni configuración de un servidor backend para ejecutar el prototipo.

### Requisitos

- Navegador web.
- Conexión a Internet para las funciones que utilizan servicios externos, como la traducción.

## Accesibilidad

Mente Sana incorpora prácticas de accesibilidad web para facilitar su utilización mediante tecnologías de asistencia.

Entre ellas:

- Estructura HTML semántica.
- Encabezados organizados jerárquicamente.
- Textos alternativos en imágenes informativas.
- Etiquetas accesibles para formularios.
- Nombres accesibles para botones y controles.
- Navegación mediante teclado.
- Estados de enfoque visibles.
- Mensajes dinámicos mediante `aria-live` y `role="status"`.
- Enlace para saltar directamente al contenido principal.
- Actualización del atributo `lang` al cambiar de idioma.
- Compatibilidad con lectores de pantalla como NVDA.
- Soporte para `prefers-reduced-motion`.

Estas características buscan facilitar que personas con discapacidad visual puedan interpretar y navegar el contenido mediante lectores de pantalla.

## Sistema de idiomas

El sitio incorpora un selector de idioma que permite traducir el contenido mediante Google Translate.

Idiomas configurados:

- Español
- English
- Français
- Português
- Italiano
- Deutsch

La traducción requiere conexión a Internet.

## Estado del proyecto

Mente Sana se encuentra desarrollado como prototipo funcional frontend.

La versión actual permite demostrar la navegación, interfaz, interacciones principales, actividades, gamificación, accesibilidad y concepto general de la plataforma.

Algunas funcionalidades avanzadas, como autenticación completa, base de datos, almacenamiento centralizado de usuarios y una implementación avanzada de inteligencia artificial, forman parte de futuras etapas de desarrollo.

## Uso básico

1. Ingresar a la página principal.
2. Explorar los temas de salud mental disponibles.
3. Acceder a las actividades de bienestar.
4. Registrar el estado emocional cuando corresponda.
5. Completar actividades para obtener Mentas y avanzar en el progreso.
6. Utilizar el espacio personal para consultar la experiencia del usuario.
7. Interactuar con Mimo mediante el chatbot.
8. Consultar el muro de la comunidad y los recursos de ayuda.
9. Utilizar el selector de idioma para cambiar el idioma del contenido.

## Consideraciones

Mente Sana tiene un enfoque de mente sana educativo y preventivo. Su contenido no sustituye el diagnóstico, evaluación o tratamiento realizado por profesionales de la salud mental.

## Proyecciones a futuro

Como siguientes etapas de desarrollo, se contempla ampliar Mente Sana con las siguientes funcionalidades:

- Backend y base de datos: implementar una arquitectura que permita almacenar de forma segura la información y el progreso de los usuarios.
- Personalización: desarrollar recomendaciones de actividades según el estado emocional y las preferencias del usuario.
- Ampliacion: ampliar el sistema de Mentas, logros, rachas y personalización de Mimo.
- Accesibilidad: continuar realizando pruebas con lectores de pantalla, navegación por teclado y diferentes tecnologías de asistencia.
- Recursos de ayuda: ampliar y adaptar los recursos de apoyo y emergencia según la ubicación del usuario.
- Multidioma: ampliar la disponibilidad del contenido a más idiomas y mejorar progresivamente la calidad de las traducciones.
- Aplicación móvil: evaluar el desarrollo de una versión móvil para facilitar el acceso.

Estas proyecciones permitirían evolucionar el prototipo actual hacia una plataforma integral de bienestar emocional, manteniendo como principios fundamentales la accesibilidad, privacidad, seguridad y acompañamiento responsable.
